# DUPUY FRANCOISE

Android operations app for shift scheduling, procurement requests, guard patrol logs, and facility bookings.

The app stores records locally on the device, uses no backend service, and requests no Android permissions.

## Project layout

- `lib/` contains the Flutter Android app.
- `android/` contains the Android platform project and release signing files.
- `web/` contains the standalone static landing page.
- `docs/` contains Play Store text assets, graphics, data safety export, and screenshots.
